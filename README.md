# 🚀 RCO App – Local Development Guide

Welcome to **RCO App**!

Follow the steps below to run the project locally on your computer.

---

## 📦 Step 1 — Install Node.js

Download and install **Node.js (v18 or higher)**:

👉 https://nodejs.org

> Node.js automatically installs **npm** (Node Package Manager), which is required for this project.

---

## 📥 Step 2 — Download the Project

1. Open the GitHub repository.
2. Click **Code → Download ZIP**.
3. Extract the ZIP file to your preferred location.

Example:

```bash
Desktop/rco-app
```

---

## 💻 Step 3 — Open a Terminal

### Windows

Open:

* Command Prompt (CMD)
* PowerShell
* Windows Terminal

### macOS / Linux

Open:

* Terminal

Navigate to the project folder:

```bash
cd Desktop/rco-app
```

---

## 📚 Step 4 — Install Dependencies

Install all required packages:

```bash
npm install
```

This will install:

* React
* Vite
* Three.js
* Other project dependencies

---

## ⚡ Step 5 — Start the Development Server

Run:

```bash
npm run dev
```

Vite will launch a local development server.

Typical URL:

```text
http://localhost:5173
```

Open the URL in your browser.

### Features

✅ Fast Refresh

✅ Hot Reloading

✅ Instant Development Updates

Any saved file changes will automatically appear in the browser.

---

## 🏗️ Step 6 — Build for Production (Optional)

Create an optimized production build:

```bash
npm run build
```

Generated files will be placed inside:

```text
dist/
```

You can deploy the `dist` folder to:

* Netlify
* Vercel
* Cloudflare Pages
* GitHub Pages
* Any Static Hosting Provider

---

## 📢 Advertising Scripts Notice

The application includes:

* Native Banner Ads
* Popunder Ads

These scripts require an active internet connection.

### Local Development Behavior

When running locally:

* Ad scripts may not load.
* No errors will occur.
* The application will continue functioning normally.

This is expected behavior and does not affect testing or development.
